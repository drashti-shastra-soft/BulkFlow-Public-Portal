# 🚚 BulkFlow – Public Portal

**BulkFlow Public Portal** is a responsive ASP.NET web application designed to provide customers and business partners with an online platform for managing bulk orders and related activities.

The portal allows users to access their accounts, place bulk orders, track order progress, check shipment status, and download invoices through a user-friendly interface.

It integrates with the BulkFlow Web API to provide application functionality and data communication.

## 🌐 Live Website

**Visit Website:** [https://bulk-flo.com/](https://bulk-flo.com/)

## ✨ Key Features

- **User Registration:** Allows customers and partners to register their accounts.
- **Secure Login:** Provides secure account authentication.
- **Dashboard:** Provides access to important account and order information.
- **Bulk Order Management:** Allows customers to place and manage bulk orders.
- **Order Tracking:** Helps users monitor their order progress.
- **Shipment Tracking:** Displays shipment and delivery status.
- **Invoice Management:** Allows users to view and download invoices.
- **Account Management:** Provides account-related information and management.
- **API Integration:** Communicates with the BulkFlow Web API.
- **Real-Time Updates:** Supports timely updates for relevant order and shipment information.
- **Responsive Design:** Provides a user-friendly experience across desktop, tablet, and mobile devices.

## ⚙️ Getting Started

### Prerequisites

- Visual Studio
- Compatible .NET SDK / Targeting Pack
- NuGet Package Manager
- BulkFlow Web API access
- SQL Server (if required by the application)

### Installation

**1. Clone the repository**

```bash
git clone https://github.com/drashti-shastra-soft/BulkFlow-Public-Portal.git
```

**2. Navigate to the project directory**

```bash
cd BulkFlow-Public-Portal
```

**3. Open the solution**

Open the following solution file using Visual Studio:

```text
BulkFlowAgenciesLLP.sln
```

**4. Restore NuGet Packages**

```bash
dotnet restore
```

**5. Configure Application Settings**

Configure the required API base URL, database connection string, authentication settings, and other environment-specific application settings.

Never commit production credentials, passwords, API keys, or sensitive configuration values to GitHub.

**6. Build the Project**

```bash
dotnet build
```

**7. Run the Application**

Select the appropriate web application project as the startup project in Visual Studio and run the application.
